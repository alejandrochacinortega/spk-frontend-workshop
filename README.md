# Spk Frontend Workshop: TypeScript warm-up

Small TypeScript exercises that run in the terminal. No browser needed.

## Getting started

1. Install Node.js 20 or newer (`node -v`).
2. Run `npm install` once.
3. Open the file in `src/` for your demo and follow the `TODO` comments.
4. Run it with the command written at the top of the file, for example `npm run hello`.

You only edit files in `src/`. The `dist/` folder is written by the TypeScript compiler.

## Demos

| Branch | File | Command | Topic |
| --- | --- | --- | --- |
| `101-0a-ts-hello-start` | `src/1-hello.ts` | `npm run hello` | Compile and run, inference, the first errors |
| `101-0b-ts-functions-start` | `src/2-functions.ts` | `npm run functions` | Typed parameters and return values, optional parameters, `void` |
| `101-0c-ts-objects-start` | `src/3-objects.ts` | `npm run objects` | Object types, arrays, `any`, `undefined`, literal unions |
